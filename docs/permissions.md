# Initial permission catalogue

| Module | Permission code | Purpose |
|---|---|---|
| System | `system:user:view` | View users |
| System | `system:user:manage` | Create, edit and disable users |
| System | `system:role:view` | View roles and permission assignments |
| System | `system:role:manage` | Manage non-system roles |
| System | `system:dictionary:manage` | Manage dictionary items |
| CRM | `crm:customer:view` | View customers within view scope |
| CRM | `crm:customer:create` | Create customers |
| CRM | `crm:customer:update` | Update customers within edit scope |
| CRM | `crm:customer:transfer` | Change customer owner |
| CRM | `crm:contact:sensitive:view` | View unmasked contact details |
| CRM | `crm:contact:sensitive:export` | Export sensitive contact details |
| CRM | `crm:follow_up:create` | Add follow-up records |
| CRM | `crm:follow_up:void` | Void a follow-up with a reason |
| Notify | `notify:channel:manage` | Manage encrypted notification channels |
| Notify | `notify:delivery:view` | View and retry deliveries |
| Audit | `audit:log:view` | View immutable audit logs |
